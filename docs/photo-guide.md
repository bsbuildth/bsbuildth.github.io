# 📸 ไกด์ถ่ายรูปหน้างาน — แบบไม่ติดใบหน้า (BSBuildTh)

ถ่ายด้วยมือถือได้ทั้งหมด ไม่ต้องมีช่างภาพ ไม่ต้องโชว์หน้าใคร
เป้าหมาย: ให้ลูกค้าเห็น **"งานจริง ฝีมือจริง ความโปร่งใส"** โดยไม่มีใบหน้าคนเลย

---

## 🥇 ลำดับความสำคัญ (ถ่ายอันไหนก่อน)

### 1. Before – After (สำคัญที่สุด)
- ถ่าย **มุมเดียวกัน ระยะเดียวกัน** ก่อนเริ่มงาน และหลังงานเสร็จ
- แนะนำ: ยืนจุดเดิม ถ่ายแนวนอน — คู่เดียวขายงานได้ทั้งโปรเจกต์
- ใช้กับ: ส่วน Before/After บนเว็บ, การ์ดผลงาน, โพสต์ Facebook

### 2. รูป Hero มุมกว้าง (รูปแรกของเว็บ)
- บ้าน/หน้างานที่เสร็จสวยที่สุด ถ่ายมุมกว้าง **ตอนไม่มีคนในเฟรม**
- แสงเช้า/เย็น (golden hour) สวยสุด
- อัปโหลดที่: แอดมิน → 🎬 Hero

### 3. มือ + เครื่องมือ (ระยะใกล้)
- ถ่ายเฉพาะ **มือกับงาน**: ฉาบปูน ปูกระเบื้อง วัดระดับน้ำ เชื่อมเหล็ก ทาสี
- มุมถ่าย: ข้างๆ หรือเหนือไหล่ — เห็นแค่มือ/แขน ไม่เห็นหน้า
- สื่อ "ฝีมือช่าง" ได้ดีที่สุดโดยไม่ต้องเห็นหน้า

### 4. ช่างหันหลัง / มุมไกล
- ช่างใส่หมวกนิรภัย **หันหลังให้กล้อง** กำลังทำงาน
- หรือถ่ายไกลจนคนตัวเล็ก (เห็นบรรยากาศหน้างาน ไม่เห็นหน้า)
- สื่อ "ทีมงานทำงานจริง มีมาตรฐานความปลอดภัย"

### 5. ดีเทลงานเสร็จ (close-up)
- รอยต่อกระเบื้องตรงเป๊ะ, บัวพื้น-ฝ้าเรียบ, ผิวสีเนียน, โครงเหล็กเชื่อมเรียบร้อย
- ถ่ายใกล้ๆ ชัดๆ — ลูกค้าที่ดูเป็นจะรู้ทันทีว่างานละเอียด

### 6. วัสดุ / อุปกรณ์
- กองวัสดุที่เห็นยี่ห้อชัด (ปูน เหล็ก กระเบื้อง) = ความโปร่งใสเรื่องวัสดุ
- เครื่องมือจัดเรียงเป็นระเบียบ = ความเป็นมืออาชีพ

### 7. ระหว่างดำเนินการ (ทุก milestone)
- ถ่ายเก็บทุกช่วงสำคัญ: รื้อถอน → โครงสร้าง → ระบบ → ผิวงาน → เสร็จ
- ใช้กับ: "ภาพระหว่างดำเนินการ" ในหน้าผลงาน + ส่งรายงานลูกค้า

## 💡 เคล็ดลับถ่ายให้สวย (มือถือ)

| เรื่อง | ทำแบบนี้ |
|---|---|
| แสง | ถ่ายตอนกลางวัน เปิดไฟทุกดวงถ้าในบ้าน หลีกเลี่ยงย้อนแสง |
| แนวภาพ | **แนวนอน 16:9** เป็นหลัก (พอดีกับเว็บ) |
| ความนิ่ง | ถือสองมือ หรือพิงกำแพง กดชัตเตอร์เบาๆ |
| ความสะอาด | เก็บขยะ/ของเกะกะออกจากเฟรมก่อนถ่าย 1 นาที ภาพดูแพงขึ้นมาก |
| เส้นตรง | เล็งให้เสา/ขอบประตูตั้งตรง (เปิด Grid ในกล้องช่วยได้) |
| จำนวน | ถ่ายเผื่อ 5–10 รูปต่อจุด แล้วค่อยคัด |

## 🚫 สิ่งที่ห้าม
- ❌ ใบหน้าคน (ทุกคน รวมถึงลูกค้า/เพื่อนบ้าน) — ถ้าติดมา ครอปออกหรือไม่ใช้
- ❌ ป้ายทะเบียนรถ, บ้านเลขที่ชัดๆ, เอกสารที่มีข้อมูลส่วนตัว
- ❌ ภาพ AI ปลอมเป็น "ผลงานจริง" (ใช้ AI ได้เฉพาะภาพประกอบ/Reference ที่ไม่อ้างว่าเป็นงานเรา)
