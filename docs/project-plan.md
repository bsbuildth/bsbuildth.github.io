## สิ่งที่ตรวจรับแล้ว

- ใบเสนอราคาตัวอย่างคำนวณ 55,010.00 + 44,500.00 = 99,510.00 บาท
- ส่วนลดท้ายบิลหักก่อนคำนวณ VAT และยอดสุทธิ โดยไม่มีคอลัมน์ส่วนลดในรายการ
- งวดชำระรวม 100% และงวดสุดท้ายรับเศษสตางค์
- รายการฟรีและรายการที่ลูกค้าจัดหาเองไม่เพิ่มยอดเรียกเก็บ
- ใบเสนอราคาเก็บ revision ที่ออกแล้วและป้องกันเลขเอกสารซ้ำ
- ใบเสร็จที่ออกแล้วแก้ไขไม่ได้ และพิมพ์ต้นฉบับ/สำเนาแยกหน้า
- เลขเอกสารว่างจะสร้างเป็น `QT-YYYYMM-ลำดับ` หรือ `RC-YYYYMM-ลำดับ` ด้วย transaction และตรวจเลขที่ออกใช้แล้ว
- ข้อมูลบริษัทบันทึกเป็นค่าเริ่มต้นส่วนตัวและนำไปใช้กับเอกสารใหม่ได้
- จำนวนเงินรวมแสดงเป็นคำอ่านภาษาไทยทั้งใบเสนอราคาและใบเสร็จ
- เอกสารยาวซ้ำหัวตาราง ไม่ตัดแถวกลางข้อความ และไม่แยกบล็อกลายเซ็น
- ผู้ใช้ทั่วไปอ่านหรือเขียน quotations, revisions และ receipts ไม่ได้ตาม Firestore Rules
- Pull Request #1–#8 ผ่าน CI และรวมเข้า `main`; งานที่เปลี่ยนตัวเว็บผ่าน GitHub Pages deploy แล้ว

## งานปรับปรุงที่ยังเลือกทำเพิ่มได้

1. เพิ่ม PDF renderer เพื่อดาวน์โหลดไฟล์ตรงและควบคุมเลขหน้าหลายหน้าเหมือนกันทุกอุปกรณ์ โดยต้องรักษาฟอนต์ไทยและคุณภาพตัวอักษร
2. เพิ่มการเซ็นด้วย S Pen/Apple Pencil ตามรายละเอียดใน [แผนเครื่องมือใบเสนอราคา](quotation-tool-plan.md) และทดสอบกับ Galaxy S25 Ultra และ iPad จริง
3. เพิ่มปุ่ม “แชร์ PDF ให้ AI ตรวจ” ผ่านเมนูแชร์ของระบบ รองรับการเลือกแอป ChatGPT/Gemini เมื่อเครื่องติดตั้งและประกาศเป็นปลายทางแชร์ พร้อมทางเลือกดาวน์โหลดไฟล์และคัดลอกคำสั่งตรวจเมื่อแชร์ตรงไม่ได้
4. เพิ่ม “สำเนาสำหรับ AI” ที่ซ่อนลายเซ็น เบอร์โทร เลขผู้เสียภาษี และเลขบัญชีโดยค่าเริ่มต้น ผู้ใช้ต้องเลือกเองหากต้องการแนบข้อมูลดังกล่าว
5. ทดสอบเอกสารยาวกับเครื่องพิมพ์จริงอย่างน้อยหนึ่งรุ่น หลังจากตรวจ PDF 70 รายการผ่านแล้ว
6. ยืนยันว่าจะใช้ Google Apps Script/LINE/อีเมลแจ้งเตือนต่อหรือยกเลิก
7. พิจารณาฝังฟอนต์เอกสารที่มีสิทธิ์ใช้งาน หากต้องการให้รูปแบบตัวอักษรเหมือนกันทุกเครื่อง

งานในรายการนี้ไม่ขวางการสร้าง แก้ไข บันทึก ออกเอกสาร และพิมพ์ใบเสนอราคา/ใบเสร็จในระบบปัจจุบัน
