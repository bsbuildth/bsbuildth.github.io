## สิ่งที่ตรวจรับแล้ว

- ใบเสนอราคาตัวอย่างคำนวณ 55,010.00 + 44,500.00 = 99,510.00 บาท
- ส่วนลดท้ายบิลหักก่อนคำนวณ VAT และยอดสุทธิ โดยไม่มีคอลัมน์ส่วนลดในรายการ
- งวดชำระรวม 100% และงวดสุดท้ายรับเศษสตางค์
- รายการฟรีและรายการที่ลูกค้าจัดหาเองไม่เพิ่มยอดเรียกเก็บ
- ใบเสนอราคาเก็บ revision ที่ออกแล้วและป้องกันเลขเอกสารซ้ำ
- ใบเสร็จที่ออกแล้วแก้ไขไม่ได้ และพิมพ์ต้นฉบับ/สำเนาแยกหน้า
- เลขเอกสารว่างจะสร้างเป็น `QT-YYYYMM-ลำดับ` หรือ `RC-YYYYMM-ลำดับ` ด้วย transaction และตรวจเลขที่ออกใช้แล้ว
- ข้อมูลบริษัทบันทึกเป็นค่าเริ่มต้นส่วนตัวและนำไปใช้กับเอกสารใหม่ได้
- จำนวนเงินรวมแสดงเป็นคำอ่านภาษาไทยทั้งใบเสนอราคาและใบเสร็จ
- เอกสารยาวซ้ำหัวตาราง ไม่ตัดแถวกลางข้อความ และไม่แยกบล็อกลายเซ็น
- ผู้ใช้ทั่วไปอ่านหรือเขียน quotations, revisions และ receipts ไม่ได้ตาม Firestore Rules
- Pull Request #1–#8 ผ่าน CI และรวมเข้า `main`; งานที่เปลี่ยนตัวเว็บผ่าน GitHub Pages deploy แล้ว
