# แนวคิดเว็บไซต์ 3D — พักไว้ตามคำขอ

สถานะ: แผนเท่านั้น งานค้างในเครื่องเสร็จแล้ว แต่ยังไม่เริ่มดีไซน์หรือเปลี่ยนหน้าเว็บจนผู้ใช้อนุมัติเฟส 3D หลังเปิดใช้ชุดปัจจุบัน
แนวคิดที่เสนอเอง: บ้านค่อย ๆ ประกอบเมื่อเลื่อนหน้า พร้อมเลือกมุมภายนอก/ห้องครัว/ภายใน แล้วเชื่อมสู่ผลงานจริงและการขอราคา ไม่ลอกวิดีโอ YouTube
โทนกราไฟต์ ขาว และทองแดง; โมเดลต้องแยกจากผลงานจริง; มือถือใช้ฉากเบาและภาพสำรอง; รองรับ reduced motion
ก่อนเริ่ม: ส่งต้นแบบหน้าแรกและงบขนาดโมเดลให้ตรวจ ขอบเขตรุ่นแรกคือหน้าแรก โมเดลบ้าน และการเลื่อนประกอบ ไม่เพิ่มฟีเจอร์ที่ยังไม่อนุมัติ
